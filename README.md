# 小學學習系統

提供國小學生使用的數學與國文互動學習網站，包含闖關、朗讀、評量、獎勵商城及角色換裝。

## 目前功能

- 一、二年級數學題型與限時闖關
- 形狀偵探隊：平面形狀、正方體／長方體及積木數量
- 小一立方體數量：排、柱、層、加法與數量估計
- 小二立方體空間推理：長寬高、前後遮擋、俯視、補成立體與乘法估計
- 測量實驗室：時鐘讀寫、重量比較及量角器判讀
- 可擴充的 `math-games.json` 遊戲題庫
- 200 字國文學習庫及聽音選字
- 題目自動朗讀、靜音及自動下一題控制
- 班級排行、成就、簽到、XP 與星星幣
- 六種初始角色與性別相容防呆
- 獨立上衣、下身、髮型、帽子、鞋履及手持道具
- 教師端學生、班級、字彙與獎勵設定

## 線上發布

`main` 分支更新後，GitHub Actions 會自動部署至 GitHub Pages。

## 本機預覽

請透過本機 HTTP server 開啟 `index.html`；直接使用 `file://` 可能限制資料載入與瀏覽器功能。

## 資料與隱私

目前學習紀錄、角色選擇與獎勵資料保存在使用者瀏覽器的 localStorage，不會跨裝置同步。正式讓真實班級使用前，應加入伺服器帳號、權限、資料庫、備份及隱私政策；公開版本請勿預載真實學生個資。
